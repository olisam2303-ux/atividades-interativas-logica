ATIVIDADE PROPOSTA

O que vocês vão resolver

Ao longo de 4 aulas, vocês vão construir — do zero — o sistema da Papelaria Ponto Certo. Aula 1: um menu simples que executa uma opção e termina. Aula 2: o mesmo menu reorganizado em funções, com validação da opção digitada. Aula 3: o menu passa a ficar em execução contínua (while/break) e ganha a opção de cadastrar produto. Aula 4: o cadastro passa a validar o preço e o menu ganha a opção de consultar produto numa lista.

OBJETIVOS

O que vocês vão aprender aqui

  • ✓Compreender o fluxo de um programa com menu: entrada, decisão, saída e repetição.
  • ✓Organizar o código em funções, cada uma com uma responsabilidade específica.
  • ✓Validar a opção informada pelo usuário antes de executar qualquer ação.
  • ✓Usar while e break para manter o menu em execução até a escolha de saída.
  • ✓Ampliar o projeto com uma lista de produtos, validação de preço e consulta.

ENTENDA

Como o menu da Papelaria Ponto Certo funciona

Use o diagrama como mapa da atividade: ele mostra a estrutura que o programa de vocês precisa seguir.

Entrada, decisão, saída e repetição: todo programa com menu segue esse fluxo (caixas eletrônicos e sistemas de atendimento funcionam assim).

A validação confere a opção antes de chamar qualquer função — assim o programa nunca tenta executar uma ação que não existe.

while True repete o menu para sempre; só break (na opção 0) encerra o laço. A lista guarda cada produto como [nome, preço].

FLUXOGRAMA

O menu completo: cadastrar, consultar, sair

O fluxograma mostra o sistema final (Aula 4): o menu recebe a opção e decide entre cadastrar, consultar ou sair. Cadastrar e consultar sempre voltam ao menu; só a opção 0 encerra o programa com break.

As linhas tracejadas são a repetição: cadastrar, consultar ou errar a opção sempre volta ao início do menu. Só a opção 0 sai do laço.

Como ler o fluxograma

  1. 1Os três losangos testam a opção em sequência — é exatamente o if/elif/elif/else que vocês vão escrever.
  2. 2Cadastrar e consultar têm caixas verdes porque devolvem o fluxo ao menu — nenhuma das duas encerra o programa.
  3. 3Só a opção 0 chega ao FIM, com break. Qualquer outro valor digitado cai na caixa "Opção inválida" e também volta ao menu.

PROCEDIMENTOS

Construam o sistema, aula a aula

Quatro etapas, uma por aula: menu simples, funções e validação, cadastro com repetição, e validação de preço com consulta.

1
Aula 1 — Executando o primeiro programa com menu
Como pensar: o programa abaixo só executa uma opção e termina — é esperado. A repetição vem só na Aula 3.
print("=== MENU ===") print("1 - Ver mensagem") print("0 - Sair") opcao = input("Escolha: ") if opcao == "1": print("Bem-vindo!") if opcao == "0": print("Encerrando...")
2
Aula 2 — Organizando e validando o programa do menu
Como pensar: criem mostrar_menu() e mostrar_mensagem(), movendo para cada uma só o que é da sua responsabilidade. Depois acrescentem um if para "Opção inválida" quando a opção não for 1 nem 0.
3
Aula 3 — Construindo o menu do projeto: Papelaria Ponto Certo
Como pensar: envolvam o menu num while True, troquem o segundo if por elif opcao == "0": break, e criem cadastrar_produto() para guardar [nome, preco] numa lista chamada produtos.
4
Aula 4 — Ampliando o sistema com validação e consulta de produtos
Como pensar: no cadastro, repitam a leitura do preço enquanto ele for menor ou igual a zero. Criem consultar_produto(), que percorre produtos com um for comparando o nome buscado.
