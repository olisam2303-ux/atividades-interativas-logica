ATIVIDADE PROPOSTA

O que vocês vão resolver

Vocês foram contratados como desenvolvedores juniores da Distribuidora Alfa. Toda noite o sistema precisa gerar dois arquivos automaticamente: o relatorio_estoque.txt, refeito do zero a cada execução, e o historico_alertas.txt, que registra produtos com estoque baixo e deve crescer a cada dia sem perder os dados anteriores. Escolher o modo de escrita errado apaga dados — por isso a decisão vem antes do código.

OBJETIVOS

O que vocês vão aprender aqui

  • ✓Diferenciar os modos de escrita de arquivo e seus efeitos sobre conteúdo já existente.
  • ✓Aplicar write() e writelines() para gerar arquivos formatados.
  • ✓Decidir conscientemente entre sobrescrever e acrescentar, conforme o propósito do arquivo.
  • ✓Combinar leitura e escrita em um único script de geração de relatórios.
SOLUÇÃO DIGITAL

Ferramenta usada nesta aula

PY
Python (IDE) + arquivos locais
O programa gera arquivos de verdade na pasta do projeto. Abram os arquivos gerados em um editor de texto para conferir o resultado — e executem duas vezes para ver a diferença entre os modos.
ENTENDA

Dois arquivos, dois comportamentos

A diferença entre os dois não é técnica, é de <b>propósito</b>: um é uma fotografia do estoque de hoje; o outro é um histórico que não pode perder o passado.

PROCEDIMENTOS

Gerem os arquivos

1
Entendendo os modos de escrita.
Como pensar: Testem cada modo em um arquivo de rascunho antes de responder — especialmente o "x", que tem um comportamento bem diferente dos outros dois.
ModoComportamento geralO que acontece se o arquivo já existir?
"w"Cria ou sobrescreve
"a"Cria ou acrescenta
"x"Criação exclusiva
2
Gerem o relatório de estoque no formato pedido.
Como pensar: O arquivo precisa sair exatamente com o cabeçalho, uma linha por produto com o preenchimento de pontos, e o total no fim.
3
Registrem os alertas de estoque baixo.
Como pensar: Primeiro identifiquem quais produtos têm quantidade menor que o mínimo; depois gravem cada um no formato com data, nome, estoque e mínimo.
ProdutoQuantidadeMínimoDispara alerta?

4
Executem o programa duas vezes e observem o histórico.
Como pensar: Essa é a parte que só se aprende vendo: rodem, abram o arquivo, rodem de novo e abram outra vez.
5
Unam leitura e escrita em um único script.
Como pensar: O script final lê os dados de estoque.csv, gera o relatório com modo "w" e registra os alertas com modo "a".
6
Avaliação e reflexão.
Como pensar: A segunda pergunta é a mais séria: em sistema bancário, escolher o modo errado não é um bug de formatação — é perda de registro contábil.
