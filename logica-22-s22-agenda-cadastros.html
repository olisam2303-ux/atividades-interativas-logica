ENTENDA

Como uma lista guarda vários dados na memória

Os exemplos abaixo usam uma lista fictícia (nomes), só para mostrar como índice, append(), in, for e len() funcionam — a lista de produtos da Papelaria é a que vocês vão testar no Relatório.

Uma lista guarda vários valores sob um único nome; cada posição é identificada pelo seu índice.

OperaçãoObjetivoComo é feita
CadastrarAdicionar um novo dado à listaappend()
ConsultarVerificar se um dado específico está armazenadocomparação com in
ListarExibir todos os dados armazenadosfor

Essas são as três operações que todo cadastro em memória precisa ter — é o que o sistema da Papelaria vai reunir ao final da Semana 22.

append() sempre adiciona ao final; in verifica presença; for percorre um elemento por vez; len() informa o total de elementos.

FLUXOGRAMA

O menu completo: cadastrar, consultar, listar, sair

O fluxograma mostra o sistema final (Aula 4): o menu recebe a opção e decide entre cadastrar, consultar, listar ou sair. As três primeiras ações sempre voltam ao menu; só a opção 0 encerra o programa com break.

As linhas tracejadas são a repetição: cadastrar, consultar, listar ou errar a opção sempre volta ao início do menu. Só a opção 0 sai do laço.

Como ler o fluxograma

  1. 1Os quatro losangos testam a opção em sequência — é o if/elif/elif/elif/else que o menu final usa.
  2. 2Cadastrar, consultar e listar têm caixas verdes porque devolvem o fluxo ao menu — nenhuma das três encerra o programa.
  3. 3Só a opção 0 chega ao FIM, com break. Qualquer outro valor digitado cai na caixa "Opção inválida" e também volta ao menu.

PROCEDIMENTOS

Guardem os produtos na memória, aula a aula

Quatro etapas, uma por aula: índices e append(), as três operações completas, retomada do projeto, e listagem integrada ao menu final.

1
Aula 1 — Como guardar dados sem usar arquivo
Como pensar: digitem o código abaixo exatamente como está e executem. Depois façam, uma de cada vez, as alterações pedidas — sempre observando o que muda no terminal antes de passar para a próxima.
produtos = [] produtos.append("Caderno") produtos.append("Caneta") produtos.append("Borracha") print(produtos)
2
Aula 2 — Incluir, consultar e listar: a lógica por trás
Como pensar: a lista já existe. Preencham cada lacuna com o código da operação indicada no comentário: cadastro (append()), consulta (if/else com in) e listagem (for).
produtos = ["Caneta", "Caderno", "Borracha"] # Cadastro ___________________ # Consulta ___________________ # Listagem ___________________
3
Aula 3 — Cadastrando e consultando no projeto
Como pensar: retomem o projeto da Papelaria Ponto Certo (as funções cadastrar_produto() e consultar_produto(), da Semana 21) e testem as duas de novo, prestando atenção em como as duas usam a mesma lista produtos.
4
Aula 4 — Ampliando o cadastro com listagem
Como pensar: criem listar_produtos() com um for e integrem a opção 3 ao menu. Pensem no que o programa deve fazer quando a lista estiver vazia, e usem len() para mostrar o total de produtos cadastrados.
