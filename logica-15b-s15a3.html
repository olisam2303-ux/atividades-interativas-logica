ATIVIDADE PROPOSTA

O que vocês vão resolver

Um sistema de monitoramento climático registra as temperaturas médias diárias de uma cidade. Os valores ficam em uma lista Python e o sistema precisa responder perguntas simples: qual foi a média do período, se uma temperatura específica ocorreu, e quais foram a maior e a menor registradas. Lista de trabalho: temperaturas = [22, 25, 21, 24, 26, 23, 22].

OBJETIVOS

O que vocês vão aprender aqui

  • ✓Percorrer uma lista acumulando valores para calcular soma e média.
  • ✓Implementar uma busca linear, verificando se um valor existe na lista.
  • ✓Identificar maior e menor valor durante um único percurso.
  • ✓Justificar a inicialização das variáveis de acumulação e de extremos.

PROCEDIMENTOS

Resolvam os seis desafios

1
Desafio 1 — Analisem a lista de dados.
Como pensar: Além de contar, pensem: por que uma lista é a estrutura adequada para guardar uma sequência de medições diárias?
2
Desafio 2 — Completem o percurso.
Como pensar: É o mesmo esqueleto da aula anterior. Depois de completar, expliquem por que essa condição não deixa o índice estourar.
i = ___ while i < __________: print(temperaturas[i]) i += 1
3
Desafio 3 — Completem o cálculo da soma.
Como pensar: A cada volta, o acumulador recebe o valor da posição atual. Qual expressão representa “o valor da posição atual”?
soma = 0 i = 0 while i < len(temperaturas): soma = soma + __________ i += 1
4
Desafio 4 — Completem o cálculo da média.
Como pensar: Média é soma dividida pela quantidade. Como obter a quantidade sem contar na mão?
media = soma / __________
5
Desafio 5 — Completem a busca linear.
Como pensar: A comparação precisa confrontar o valor da posição atual com o valor procurado. Pensem também: o que acontece quando o valor aparece duas vezes?
procurada = 24 encontrou = False i = 0 while i < len(temperaturas): if temperaturas[i] == __________: encontrou = True i += 1
6
Desafio 6 — Maior e menor temperatura.
Como pensar: Expliquem a inicialização e descrevam o que acontece a cada volta do laço: que comparação é feita e quando as variáveis mudam de valor.
