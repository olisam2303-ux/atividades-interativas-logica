ATIVIDADE PROPOSTA

O que vocês vão resolver

Vocês vão construir um gerenciador de tarefas dividido em dois arquivos: main.py, o módulo de interface, que exibe o menu e conversa com o usuário; e tarefas.py, o módulo de lógica, que guarda e manipula os dados. A aplicação cresce em três partes: primeiro a fundação (menu), depois adicionar e listar, e por fim concluir e remover.

ENTENDA

Dois arquivos, duas responsabilidades

A ideia central da semana: quem <b>fala com o usuário</b> não é quem <b>mexe nos dados</b>. Essa separação é o que permite trocar o menu sem tocar na lógica — e vice-versa.

Construam a aplicação em três partes

# tarefas.py — módulo de lógica lista_de_tarefas = []
2
Parte 1 — Montem o menu em main.py e testem a fundação.
Como pensar: Neste momento as opções ainda mostram mensagens temporárias. Rodem python3 main.py e testem as opções 1, 2 e 3 antes de seguir.
# main.py — módulo de interface (versão da Parte 1) while True: print("\n=== GERENCIADOR DE TAREFAS ===") print("1. Adicionar tarefa") print("2. Listar tarefas") print("3. Sair") opcao = input("Escolha uma opção: ") if opcao == "1": print("[em breve] adicionar") elif opcao == "2": print("[em breve] listar") elif opcao == "3": print("Até logo!") break else: print("Opção inválida.")
3
Parte 2 — Escrevam adicionar_tarefa e listar_tarefas em tarefas.py.
Como pensar: Cada tarefa guarda duas informações: o nome e se já foi concluída. Na listagem, o enumerate com start=1 numera para o usuário.
# tarefas.py lista_de_tarefas = [] def adicionar_tarefa(nome_tarefa): lista_de_tarefas.append({"nome": nome_tarefa, "concluida": False}) print(f'Tarefa "{nome_tarefa}" adicionada.') def listar_tarefas(): if len(lista_de_tarefas) == 0: print("Nenhuma tarefa cadastrada.") return print("\nSuas tarefas:") for indice, tarefa in enumerate(lista_de_tarefas, start=1): status = "[x]" if tarefa["concluida"] else "[ ]" print(f"{indice}. {status} {tarefa['nome']}")
4
Parte 2 — Conectem as funções ao menu e testem.
Como pensar: Em main.py, importem as funções na primeira linha e troquem as mensagens temporárias pelas chamadas. Adicionem duas ou três tarefas e listem.
# main.py — primeira linha from tarefas import adicionar_tarefa, listar_tarefas # dentro do if/elif if opcao == "1": nome = input("Nome da tarefa: ") adicionar_tarefa(nome) elif opcao == "2": listar_tarefas()

5
Parte 3 — Escrevam marcar_concluida e remover_tarefa.
Como pensar: As duas recebem o número que o usuário vê e precisam converter para índice. Validem o intervalo antes de mexer na lista — senão o programa quebra com um número fora da faixa.
def marcar_concluida(numero): indice = numero - 1 if 0 <= indice < len(lista_de_tarefas): lista_de_tarefas[indice]["concluida"] = True print("Tarefa marcada como concluída.") else: print("Número inválido.") def remover_tarefa(numero): indice = numero - 1 if 0 <= indice < len(lista_de_tarefas): removida = lista_de_tarefas.pop(indice) print(f'Tarefa "{removida["nome"]}" removida.') else: print("Número inválido.")
6
Parte 3 — Atualizem o menu e façam o teste final.
Como pensar: O menu passa a ter 5 opções. Testem a sequência completa: adicionar, listar, marcar uma como concluída, listar de novo para ver o [x], e remover.
from tarefas import adicionar_tarefa, listar_tarefas, marcar_concluida, remover_tarefa # novas opções elif opcao == "3": numero = int(input("Número da tarefa: ")) marcar_concluida(numero) elif opcao == "4": numero = int(input("Número da tarefa: ")) remover_tarefa(numero)
