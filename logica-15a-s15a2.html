ATIVIDADE PROPOSTA

O que vocês vão resolver

Uma escola está desenvolvendo um sistema em Python para analisar notas de alunos. As notas ficam em uma lista e o programa precisa percorrê-la para exibir cada valor. O sistema ainda não está pronto: algumas partes do código estão incompletas ou incorretas. O grupo vai analisar, prever comportamentos e completar o código até chegar a uma versão funcional. Lista de trabalho: notas = [7.0, 8.5, 6.0, 9.0, 5.5].

OBJETIVOS

O que vocês vão aprender aqui

  • ✓Identificar a quantidade de elementos, o primeiro e o último índice válido de uma lista.
  • ✓Definir corretamente o valor inicial da variável de índice.
  • ✓Escrever a condição de parada que percorre toda a lista sem estourar o limite.
  • ✓Explicar por que <= na condição gera erro de índice.

ENTENDA

Índices: onde começa e onde termina

Quase todo erro de percurso de lista vem de confundir <b>quantidade de elementos</b> com <b>último índice válido</b>. São números diferentes.

PROCEDIMENTOS

Resolvam os cinco desafios

1
Desafio 1 — Analisem a lista.
Como pensar: Contem os valores e prestem atenção: o índice do primeiro elemento não é 1.
2
Desafio 2 — Qual valor deve ser atribuído a i para o percurso começar corretamente?
Como pensar: O percurso precisa começar no primeiro elemento da lista — e vocês acabaram de descobrir qual é o índice dele.
3
Desafio 3 — Completem a condição de parada.
Como pensar: A condição precisa deixar o laço rodar enquanto houver elemento válido — e parar exatamente quando acabar. Use len().
4
Desafio 4 — Analisem este código com erro.
Como pensar: Simulem no papel: com i valendo 5, o que o Python tenta acessar? Depois rodem para confirmar a mensagem de erro.
i = 0 while i <= len(notas): print(notas[i]) i += 1
5
Desafio 5 — Ampliem o programa.
Como pensar: Com o percurso correto funcionando, dá para resolver problemas maiores sem mudar a estrutura do laço — só o que acontece dentro dele.
